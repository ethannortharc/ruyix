# 系统风格：Ruyix 的设计规范

2026-10-14 · Ethan 的要求：整体界面要有质感；字体和控件要统一，并且能随桌面大小自适应，就像 macOS 那样；
要有一套完整、通用的「系统风格」，像 design code 一样，调起来容易。

这份文档就是那套规范。所有值都写在一个文件里：`core/shell/tokens.css`。每个页面都只用这里的变量，所以改一处，整个
Ruyix 都跟着变。自检（`core/shell/check.mjs`）会拦下写死的字号和圆角。

## 1. 三层调节

| 层 | 调什么 | 在哪调 | 怎么起作用 |
|---|---|---|---|
| 界面大小 | 所有东西一起放大缩小：文字、控件、窗口、程序坞 | 设置 → 系统风格，或顶栏的外观菜单；`desktop.json` 的 `scale` | 桌面和窗口内容按 `--ruyix-scale` 缩放 |
| 密度 | 控件和间距占多少地方（文字只变一半） | 同上；`density`：紧凑 0.88 / 标准 1 / 宽松 1.12 | `--ruyix-density` 乘在间距、控件高度上 |
| 圆角 | 按钮、卡片、窗口的圆角 | 设置 → 系统风格；`corners`：小 0.6 / 标准 1 / 大 1.4 | `--ruyix-radius-k` 乘在圆角上 |

另外还有强调色（`accent`）、窗口底色（`tint`：中性 / 暖 / 冷，换 `--ruyix-canvas`、`--ruyix-surface*`、线条和文字的颜色）和材质
（`glass`：半透明或不透明），也在「系统风格」里。主题（`theme`）一次选好壁纸、强调色、底色和圆角（见 os.md §15）。

**自适应**：界面大小默认是「自动」，只缩小、不放大。桌面（浏览器页面）比大约 1600 × 900 小时，按比例缩小，好让这么多
内容放得下：13 寸笔记本的浏览器里约 85%，最小 80%。桌面更大时停在 100%：大屏多出来的是空间，不是更大的字。这和 Mac
一样，东西看起来多大由屏幕自己的缩放设置决定，屏幕越大显示得越多。想整体放大就手动选 110% 以上。
（2026-10-14 之前，「自动」在大屏上会放大到 130%，在 2560 宽的显示器上字和窗口都显得太大，所以改了。）

窗口也自适应：
- 桌面小时，页面窗口铺满。
- 桌面宽时，窗口给右边的小组件留出位置，在剩下的地方居中，最大 1440 × 940（`store.js` 的 `ROOMY`），位置略高于正中。
  大屏上窗口四周留出桌面，不会铺满整个屏幕。
- 挪过或拉过的窗口保持自己的大小，只在桌面放不下时缩小；它的中心在桌面上的相对位置不变。
- 插件打开的窗口（比如 Linux 应用）最大是桌面的八成左右。
- 窗口压住桌面左上角的大时钟时，时钟淡出，不会从窗口边缘露出一截。

Linux 应用：画面不跟着界面缩放（要逐像素才清楚），而是启动时告诉应用该用多大：Retina 屏用两倍像素，
文字再乘上界面大小（GTK 的 `GDK_DPI_SCALE`、Qt 的 `QT_SCALE_FACTOR`、Xvnc 的 DPI）。

## 2. 变量

### 文字

正文是 `md`，13px，和 Mac 一样。字号只有这八级（标准密度下的值）：

| 变量 | 大小 | 用在 |
|---|---|---|
| `--ruyix-text-2xs` | 10 | 徽标、最小的说明 |
| `--ruyix-text-xs` | 11 | 元信息、提示、标签 |
| `--ruyix-text-sm` | 12 | 次要文字、小按钮 |
| `--ruyix-text-md` | 13 | 正文、按钮 |
| `--ruyix-text-lg` | 14.5 | 强调、卡片标题 |
| `--ruyix-text-xl` | 17 | 页面标题 |
| `--ruyix-text-2xl` | 22 | 大数字 |
| `--ruyix-text-3xl` | 28 | 首页大标题 |

字重：`--ruyix-weight-medium`（520，控件）、`semibold`（600，标题）、`bold`（680，页面标题）。正文用 400，不写变量。
字体：`--ruyix-font`（系统字体，中文是苹方），`--ruyix-font-mono`。

### 间距

4px 网格，16 以内有 2px 的半步：`--ruyix-space-4`、`6`、`8`、`10`、`12`、`14`、`16`、`20`、`24`、`28`、`32`。
名字就是标准密度下的像素数，读代码一眼能懂。1–3px 的细微对齐不用变量。

### 控件

高度 `--ruyix-control-xs` 22 · `sm` 26 · `md` 30 · `lg` 34 · `xl` 40；左右内边距 `--ruyix-control-pad-xs` 8 ·
`sm` 10 · `md` 13 · `lg` 16 · `xl` 20。按钮、输入框、分段选择、标签页都按这个来；一般用 `md`，表格行里的小按钮用
`sm`，首页的主要操作用 `xl`。

### 圆角

`--ruyix-radius-xs` 6 · `sm` 8 · `radius` 10 · `lg` 14 · `xl` 18 · `pill`。小标签用 `xs`，按钮和输入框用 `sm`，
行和提示用 `radius`，卡片用 `lg`，大面板用 `xl`。

### 材质

- 按钮：`--ruyix-control`（受光面，上亮下暗）、`-hover`、`-lift`（细边 + 小阴影 + 顶部高光）、`-press`（按下内陷）。
- 主要按钮：`--ruyix-primary`、`-hover`、`-lift`、`-press`、`--ruyix-on-primary`。用强调色；深色模式下是更深的强调色配白字。
- 卡片：`--ruyix-card-lift`（细边 + 两层柔和阴影）。悬停时上浮 1px，阴影加深。
- 输入框：`--ruyix-field`（内陷）。焦点：`--ruyix-focus`（一圈强调色光环）。

### 桌面小组件

小组件放在壁纸上，不在窗口里，所以它们的玻璃跟着**壁纸**的明暗走（深色壁纸用深色玻璃，浅色壁纸用浅色玻璃），
和大时钟一样，不跟页面的浅色深色主题走：换了壁纸也不会发灰发脏。顶栏和程序坞也放在壁纸上，所以也按这个规则走，
就像 Mac 的菜单栏和程序坞。窗口和菜单仍然跟页面的浅色深色主题走。阴影只用小而柔的一层（`--ad-wlift`），
所在的列留出内边距装下阴影，避免阴影被滚动区域切成一块深色方框。大小只有两种：小（半列，正方形）和中（整列）。

### 颜色

见 `tokens.css` 开头：强调色、成功、警告、危险，文字四级，线两级，底色几层。浅色深色都有。

## 3. 规则（写新页面时）

1. 只用 `--ruyix-*`：不写 dsh 的 `--dsw-alias-*`，不写死颜色。
2. 字号只用 `--ruyix-text-*`，圆角只用 `--ruyix-radius-*`（4–20px 之间写死会被自检拦下）。
3. 间距用 `--ruyix-space-*`，控件高度和内边距用 `--ruyix-control-*`，这样「密度」才管得到。
4. 按钮只有三种：普通（control 材质）、主要（primary 材质，一个区域只放一个）、安静（透明，悬停才有底色）。
   一个区域里最重要的操作用主要按钮，其他用普通按钮。
5. 卡片用 `--ruyix-card-lift`，不再画实线边框。
6. 页面里的通用重置要用 `:where()`（比如 `.x-page :where(button) { font: inherit }`），不能比按钮自己的样式权重高，
   否则会把按钮的内边距、底色、字号清掉。
7. 视口单位：桌面模式下整个界面被缩放过，`vw`/`vh` 是屏幕的，会被再缩放一次。桌面外壳用 `--ad-vw`/`--ad-vh`；
   页面里尽量用百分比和容器单位。

## 4. 实现

- `core/shell/tokens.css`：全部变量。每个插件打包时都带上这份文件，没有外壳时也一样好看。
- `core/shell/desktop.js`：`SCALES`、`DENSITIES`、`CORNERS`、`scaleOf()`（自动大小的算法）、`desktopCss()`（把密度、圆角、
  强调色写到 body 上）。
- `core/shell/src/desktop/`：缩放（`.ad-root` 和页面窗口的 `zoom`）、窗口自适应（`store.js` 的 `firstRect`、`follow`）。
- `core/plugins/apps/src/vnc.jsx`：Linux 应用的画面反向抵消缩放、高清显示。
- 2026-10-14 把六个插件和外壳的样式表都换成了这些变量：字号、字重、控件高度和内边距、间距、圆角。数值按最近的一级取，
  原来的奇数值（如 7px、13px、15px）会对齐到网格，整体略紧凑一些。
