当一个节点；不同的流程有不同的结果——PDF、文件、网页、视频——都能打开来看、写意见；意见可以让流程从某一步重新开始。

## 查看器（`src/viewer.jsx`）

一个查看器，两个地方用：审阅步骤（等人的）和运行的「结果」页签（不等人的）。左边文件，中间按类型显示，右边意见。

| 类型 | 怎么显示 | 意见挂在哪 |
|---|---|---|
| Markdown | 排好版 | 选中的一段文字 |
| 文本、代码、JSON | 带行号 | 选中的文字，或点行号选几行 |
| 图片 | 原图 | 图上拖出的一块 |
| PDF | pdf.js 一页一页画出来（最多 60 页） | 某一页上拖出的一块 |
| 网页 | 在隔离的框里真的运行（脚本能跑） | 整个页面 |
| 视频、音频 | 播放器 | 某一刻 |
| 别的 | 下载 | 整个文件 |

每个文件都能下载；文本类的能直接改（存成一个新版本）；审阅还能和上一轮比。

- **PDF**：pdf.js 6.4（`vendor/pdfjs`，只放了用到的两个文件和许可证，不装整个 35 MB 的包）。第一次打开 PDF 时才加载，
  由 workbench 的 `/api/ruyix-workbench/pdfjs/…` 给。
- **网页**：框没有自己的来源（sandbox 不给 allow-same-origin），碰不到 dsh、你的登录和外面的页面，也就拿不到它旁边
  的文件——所以服务端（`lib/pages.js`）先把它引用的本地文件（样式、脚本、图片、字体，样式表里的 url()）嵌成 data:
  URL；网络上的地址照常加载；太大的、文件夹外面的不放，页面上说一声。已知的限制：模块脚本里再 import 别的文件、
  页面之间的链接不会跟着嵌进去。

## 「结果」节点（`use: 'output'`）

工作流里的一种步骤，不停下等人，像 ComfyUI 的预览节点：它记下「哪些文件是这次运行的结果」——`show` 里的路径
（可以用 `*`），不写就是到这一步为止运行做出、改过的所有文件。运行页面多一个「结果」页签：

- 有「结果」节点：列它们说的文件；没有：列运行开始以来改过的所有文件（有文件才出现这个页签）。
- 在上面写意见，意见存在运行上（`run.results.comments`），边写边存。
- **带着意见从某一步重新开始**：选一步（做东西的步骤：不含收下请求、报告、人的步骤、结果节点、分支本身），那一步和
  它后面的都再跑一遍，待改的意见写进那一步的说明（`engine.continueRun`）。文件保持现在的样子。意见标成「已交给某一步」，
  每一次重新开始都记下来。

## 审阅：退回到哪一步，现在选

以前「退回」只能回到事先写好的那一步（`back`）。现在审阅页底部可以选：这一步之前任何做东西的步骤；`back` 只是默认选中
的那个（没有写 `back` 时，默认是按意见改的那个 agent 的步骤，再不然是最近的一步）。

## agent 之间的留言：要看的时候打开

「过程」页右边多一个「agent 之间的留言」，默认收起，点开就是那次运行里 agent 互相说的话；「留言」页签照旧在。
