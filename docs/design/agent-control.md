# 一个入口：语音和对话；整个系统都能由智能体操作（设计）

2026-10-18 · Ethan（语音）：

> 我要支持能把整个系统作为一个 skill，可以通过 agent 来控制整个系统。像打开什么 APP、打开什么东西、显示什么东西、查找什么东西，
> 都可以直接通过智能体来做。包括创建什么东西——创建一个 app、创建 xdl、创建类似的什么东西，也能通过 agent 来做。现在整个系统都应该
> 能通过 agent 来控制。

> 其实本质上，Agent OS 我只想保留一个语音和一个 Chat，这是最主要的，其他的 APP 只是来给他们提供功能的。当然因为 UI，我们要借很多
> 呈现来提供更好的效果，和越用越聪明的方法。所以在操作上要尽量简单。比如我之前记很多 APP，这个 APP 做什么、那个 APP 做什么，太麻烦了。

## 要做到什么

1. **入口只有两个：语音和对话**，都交给主智能体（docs/design/main-agent.md）。你说要什么，它去找能做这件事的东西、去做、把结果摆出来给你看。
2. **应用和页面是「能力」和「呈现」**：能力给智能体用，呈现给你看结果。你不用记哪个应用做什么，智能体记。
3. **你在界面上能做的，智能体都能做**：打开、显示、查找、新建、修改、整理。规则沿用 main-agent.md：能撤销的直接做，记进工作记录、附撤销；
   撤销不了或对外的（删除、发布、发消息、花钱、批准）先出确认卡片，你点一下或说「好」才做。
4. **不只主智能体**：池子里的智能体、你 Mac 上的 Claude Code，都能把整个 Ruyix 当一个 skill 来用（同一套工具）。
5. **越用越聪明**：它记住你用什么做什么、喜欢什么样的结果，下次直接这样做。

## 现在是什么样（盘点，2026-10-18，读代码，没跑）

- 智能体能用的工具约 70 个，几乎都只给主智能体：桌面外观、开着的东西（列出 / 拿到前面 / 分组 / 收起 / 关）、会话、工作流运行和排期、
  任务（列出 / 查看 / 好了 / 再改 / 归档）、工作室、应用中心（列出 / 装 / 卸 / 开 / 关）、语音设置、对话里的卡片、网页搜索和读取。
- **缺的**（界面能做、工具做不到）：打开任意页面或设置里的某一栏；**查找**（⌘K 只搜页面、窗口、外观、设置、应用）；在查看器里打开文件或文件夹；
  在智能体页新建、修改、删除智能体，设默认；启用工作流（工具只能存草稿）；往便签里写字；工作室的素材；窗口的摆放（移动、放大、平铺）；
  开一个终端；换主智能体；查看模型、搜索的设置（只看名字，不看钥匙）。
- **两种主智能体不一样**：dsh 的主智能体多一批工具（改界面的提议、连接、盒子、智能体池、起一个多人任务），Claude Code / Codex 当主智能体时没有。
- **外面的智能体进不来**：没有哪条路能让别的智能体调用这些工具。它们只有 `ruyix desk`（提议桌面改动）、`ruyix session`、智能体之间发消息，
  以及 Ruyix 自己起的运行里的网页 / 浏览器工具。
- `ruyix-system` 这个 skill 写的是主智能体的工具；给别的智能体用，它会以为自己有这些工具。

## 设计

### 1. 一个「查找」：按要做的事找，不按应用名找

新工具 `find({ query, kinds? })`（只读）。一次查遍：

| 查什么 | 例子 |
|---|---|
| 能力 | 「剪视频」→ 视频剪辑；「看 PDF」→ 文件查看器；「画图」→ 某个装好或能装的应用 |
| 东西 | 页面、设置里的栏目、开着的东西、任务、运行、会话、工作室和它的记录、工作流、智能体、作品集里的成果、文件 |

每条结果带「怎么用它」：用哪个工具、什么参数（打开它、拿它做事、装它）。主智能体先 `find`，再做，你说的是事情不是应用名。

**能力从哪来**：每个插件、应用中心的每个应用写几句「能做什么」（中英文，动词 + 常见说法），和它的工具或打开方式放在一起。
应用中心现有的简介是底子，再加 `does: ['剪视频', '加字幕', …]` 这样的说法。没装的应用也能被找到（结果写「要先装，约 N MB」，装是能撤销的，直接做）。

### 2. 把缺的工具补齐

都注册成系统工具（shell 的 `systemTools`），这样两种主智能体、以后外面的智能体拿到的是同一套。

| 批次 | 工具 | 效果 | 说明 |
|---|---|---|---|
| 1 | `open_page({ page })`、`open_settings({ tab })` | 直接做 | 打开任意页面 / 设置里的某一栏。页面清单由页面报上来（像小组件种类那样） |
| 1 | `find` | 只读 | 见上 |
| 1 | `open_file({ path \| run+file \| session+file })` | 直接做 | 在查看器里打开文件或文件夹 |
| 1 | `terminal_open({ app?, session?, window? })` | 直接做 | 开一个终端，或接到某个会话（今天刚做的接到指定会话） |
| 1 | `desk_note({ id?, text })`、`desk_window({ id, action: front \| max \| min \| restore \| tile })` | 直接做（可撤销） | 便签、窗口摆放 |
| 2 | `agent_list`、`agent_save`、`agent_remove`、`agent_default` | 新建 / 修改：直接做（撤销 = 回到原来的定义）；删除：确认卡片 | 「建一个专门写周报的智能体」 |
| 2 | `workflow_enable` | 确认卡片 | 工作流写好了，你点「启用」 |
| 2 | `studio_material_add / remove` | 直接做（可撤销） | 工作室的素材 |
| 2 | `main_agent_set`、`models_get`、`search_get` | 换主智能体：确认卡片；查看：只读，只给名字不给钥匙 | |
| 2 | 把 dsh 主智能体独有的那批（改界面的提议、连接、盒子、智能体池）也注册成系统工具 | | 两种主智能体一样 |
| 3 | 新建各种东西 | 见第 3 节 | |

**留给你的**（不变）：钥匙和登录、批准、对外发布 / 发消息 / 花钱、盒子的出网规则和挂载。智能体可以把这些准备好，出卡片等你点。

### 3. 新建：在 Ruyix 上能工作的各种东西，都能用话建出来

Ethan：「这些创建应该就是 APP、Application，反正就是在这个 Agent OS 上可以工作的各种东西。」智能体按你的话选建哪一种：

| 你说的像 | 它建 | 工具 |
|---|---|---|
| 「做个小工具 / 看板 / 小游戏」 | **小应用**：智能体写的网页应用（HTML / JS / CSS），开成桌面上的窗口，放进程序坞和应用中心的「我做的」，也能放到桌面上当小组件 | `app_make`、`app_edit`（每次改留一个版本，撤销 = 回上一版）、`app_remove`（确认卡片） |
| 「管我的选题 / 读书笔记」（一类记录 + 对它们做的事） | **工作室**（记录 + 工作流的页面） | `studio_create`（已有） |
| 「每天早上帮我…」「以后遇到…就…」 | **工作流**、排期 | `workbench_workflow_save` + `workflow_enable` 卡片；`workbench_task_schedule`（已有） |
| 「建一个专门写周报的智能体」 | **智能体** | `agent_save` |
| 「把这个做法记成一个技能」 | **技能**（你自己的技能包） | `skill_save` |

- 小应用放在 `~/.ruyix/made/<id>/`；窗口里用隔离的 iframe（`sandbox="allow-scripts"`，不同源）打开，碰不到 Ruyix 的登录；它要用 Ruyix 的能力时
  经一个小接口，走同样的工具和同样的规则（能撤销的直接做，其余出卡片给你）。
- 建好就打开给你看；之后「把那个小工具改成…」直接改，`find` 能找到它。

### 4. 整个 Ruyix 作为一个 skill，给任何智能体用

- **一个 MCP 服务 `ruyix`**：工具 = 上面的系统工具。命令 `ruyix mcp`（标准输入输出），跟 Ruyix 走本机的 Unix 套接字（只有盒子里这个用户能连）。
  - 池子里的智能体（Ethan 定：都能用）：Agent Hub 起它们时像今天的网页、浏览器工具一样带上。
  - 你 Mac 上的 Claude Code：MCP 命令写 `nookbox exec --stdio ruyix -- ruyix mcp --as 名字`，不用另发钥匙（能进盒子本来就是你的权限）。`--stdio` 是 nookbox 0.5.12 加的：不加时，非终端的 exec 不转发输入，MCP 接不上。
- **谁在操作**：每个连进来的智能体有名字；工作记录写「谁、应谁的话、做了什么、怎么撤销」。
- **skill `ruyix-system` 分成两份**：通用的（有哪些工具、怎么找、什么直接做什么出卡片）给所有用它的智能体；主智能体专用的（卡片、桌面上的回答、[Now:] 时间）只给主智能体。
- 页面动作（打开页面、开窗口）要有一个打开着的 Ruyix 页面；没有时工具照实说「Ruyix 没开着，打开后会出现」，排队 2 分钟。

### 5. 越用越聪明

- 你确认「好了」的任务，主智能体记一条「这类事这样做」（用了什么能力、什么样子你满意）；你「再改」时记下改了什么。
- `find` 的结果按你用过的排在前面；同一件事第二次，直接用上次的方式，并说一句「按上次那样用 X 做了」。
- 记的东西在对话的记忆里（已有 `workbench_memory_*`），你能看到、能删。

### 6. 界面

- **桌面先不动，对话和语音做正门**（Ethan 定）：对话条一直在，⌘K 直接问主智能体，所有应用都能用话叫出来。页面、窗口、桌面上的回答是「呈现」。
  应用中心、程序坞照常在，但你不需要它们也能把事做完。

### 7. 窗口自动排开，排不下的进抽屉（Ethan 2026-10-19）

Ethan：「窗口打开的时候，希望能排好，不要互相覆盖。或者像抽屉一样。小应用不用独占一格。」

- **自动排开**（默认）：窗口打开、关掉、收起、拿回来时，桌面中间那块地方（左边打开的东西、右边小组件、上面顶栏、下面程序坞之间）
  重新排一次：1 个铺满；2 个左右各半；3 个最新的在左边占大块、另两个在右边上下叠；4 个田字格。页面窗口也算一个。
- **抽屉**：超过 4 个时，最久没用的收进右边的抽屉（一条窄边，露出图标和名字）；点一个，它回到格子里，换最久没用的进抽屉。
  铺满（最大化）时，其他窗口暂时进抽屉，还原时回来。
- **你自己拖过、拉过大小的**窗口留在你放的位置，不跟着排；右键「排好窗口」全部重新排。
- 设置 → 通用 → 桌面：「窗口：自动排开 / 自由摆放」。
- 智能体的 `desk_window` 照旧（拿到前面、铺满、并排……），排开是桌面自己的规矩。
- 做的人：workspace-15（桌面的窗口）。
