# 交互式桌面（设计）

2026-10-17 · Ethan：在「经典」（网页版）和「桌面」（OS 版）之外，再做一种**交互式桌面**——整个桌面就是一张图（星图或古地图）。
没有顶栏、Dock、传统图标：新建任务、收件箱、对话、应用、设置，还有正在跑的任务，都是图里的元素，点它就用它，像玩游戏地图
一样边玩边做。先做两种：星图、古地图。可以做成插件，切换过去。

他定的：

- 图**能拖能缩放**：一打开整张图正好一屏，拖着看，滚轮放大看细节；以后地方多了也放得下，有「探索大陆」的感觉。
- 点一个地方打开页面时，用**同风格的面板**：古地图是旧纸、卷轴的边框，星图是半透明的星际面板；面板里还是原来的页面。

## 怎么对应

图上的画是比喻，旁边的字写真实的名字（「应用」「收件箱 · 3」「设置」）：看画有趣，看字不会猜错。

| 系统里的东西 | 古地图 | 星图 |
|---|---|---|
| 主智能体（对话、语音） | 中央都城 | 中心的主星 |
| 运行页 | 港口 | 星港 |
| 新建任务 | 港口边的一艘船 | 星云孵化区 |
| 正在跑的任务 | 海上的岛，环路上的驿站是步骤 | 星轨，每段是一步 |
| 定时任务 | 雾里的岛 | 暗的虚线星轨 |
| 收件箱 / 审批 | 驿站（角标是件数） | 信标 |
| 工作流 | 藏书阁 | 星座 |
| 智能体 | 行会 | 舰队 |
| 应用 | 工坊镇 | 行星 |
| 连接器 | 渡口 | 中继卫星 |
| box | 城寨 | 护盾 |
| 记录（做完的任务、指标） | 史馆 | 星表 |
| 设置 | 罗盘 | 天文台 |
| 回到普通桌面 | 界碑 | 星门 |
| 日期时间 | 题框 | 星时环 |
| 其他插件的页面 | 自动长出来的村镇 | 自动长出来的小行星 |

## 做法

- **shell**：`desktop.json` 的 `mode` 多一种 `world`，`world` 选哪张图（`atlas` / `sky` / `future`）。图由插件登记在
  `window.__ruyixWorlds`（`[{ id, name: { zh, en }, render }]`，事件 `ruyix:worlds`）。交互式模式下 shell 不画顶栏、Dock、
  小组件、时钟和壁纸，只画插件给的图；窗口（页面、其他窗口）、⌘K、对话、通知、语音照常。图拿到一份 `api`：页面列表
  （名字、图标、角标）、打开页面、对话、新建任务、设置、⌘K、回到普通桌面、换图。没装插件时 `world` 模式退回普通桌面。
- **插件 `@ruyix/world`**（`core/plugins/world`）：两张图。背景是壁纸那套 GPU 画法（shell 的 `createWallpaper` 加上插件自己的
  场景），多了视角（`uV`：中心和缩放）和地标（`uMark`：位置、陆地半径、种类）；地标的图标、名字、角标、点击是一层 HTML /
  SVG，跟着视角走，字始终是同样大小。任务、智能体、消息的数据跟智能体星图 / 古地图壁纸一样，来自 `window.__ruyixActivity`。
- 面板：插件给 `.ad-root[data-world="…"]` 下的窗口换边框（古地图：纸色、墨线、卷轴两端；星图：半透明、发光细边）。

第二轮（2026-10-17，Ethan 经 workspace-ce 提的；分工：古地图、星图和页面的样子是这边，第三张科幻风格的图、接口文档 / 模板 /
技能、三张古风壁纸是 workspace-ce）：

- 一张图 = 一份定义（`registerWorld(def)`，`src/atlas.jsx`、`src/sky.jsx`），别人照着写自己的图。
- 古地图：每个地方一座岛，有起伏和光影（光从左上来），旧纸、折痕、双线图框。
- 星图：每个地方是一个星座（星和连线），任务也是星座（一步一颗星）。

第三轮（2026-10-17，Ethan）：

- 古地图：岛的形状要有艺术感、参差不齐，像真实的世界地图，每座都不一样。做法：每座岛按自己的种子长——一条长链、带几条
  半岛的一大块、被大海湾咬掉一边的月牙；都城那座多一瓣，像一块小大陆；岸边有小岛；海岸线在几个尺度上都是碎的。
- 星图：每个地方是一个**真实的星座**，按真实的赤经赤纬投影（北在上、东在左，和抬头看到的一样），星的亮度和颜色也照真的
  （参宿四橙红、参宿七蓝白）：主智能体 = 北极星和小北斗，任务 = 北斗七星，新建任务 = 昴星团（带蓝色星云），收件箱 =
  天琴座（有事等你时变琥珀色、闪），工作流 = 仙后座，智能体 = 猎户座（带猎户座大星云），应用 = 天鹅座，连接器 = 双子座，
  box = 飞马座大四边形，记录 = 狮子座，设置 = 南十字，回普通桌面 = 北冕座；别的插件的页面依次是天蝎、金牛、天鹰……
- 连线很淡，鼠标指上去那一个才亮；不放图标；名字只在鼠标指上去时出现。
- 背景是一团像真的星云：深红的氢气云团和薄纱、青色的炽热核心、一团被星光照亮的蓝色星云、暗尘的带和团，慢慢呼吸。
- 页面跟着图走：图的 `theme`（颜色、线、底、强调色、圆角）在它是桌面时盖到 <body> 上；不强制深浅色（强制深色时
  dsh 自己的底色不跟着变，半页看不清）。
- 第三张图「未来」（`src/future.jsx`、`src/future-scene.js`）：从上往下看的一座光之城。地上是六边形网格，地方附近亮、有城市灯光；
  每个地方是一座立起来的六边形平台，有自己的光色和侧面阴影。主智能体是中心的核，几圈环在转，说话时更亮；新建任务是一个传送门。
  核到每个地方有电路线，数据沿线往外流。任务是一圈全息环：做完的步骤亮，正在做的一段在流动，等人时变琥珀色闪；
  环外有刻度，环内有一圈在转，在跑时有扫描。智能体是小无人机（菱形），留言是一道光束，上面有往前跑的箭头和光点。
  窗口是发光细线边框，四角有标记，标题栏是深色玻璃；页面用冷色、青色强调色，圆角更小。平台按地名、图标同样的规则缩放，
  放大缩小时名字都不会压在平台上。
- 给别人做图：`core/plugins/world/MAKE-A-MAP.md`（每个字段、着色器能拿到的数据、主题、窗口、怎么装），
  `core/plugins/world/template/`（能直接复制改的小插件，画一张「蓝图」，检查里会构建它），技能 `ruyix-world-map`
  （`core/shell/skills/`：教智能体照着做；安装那一步由人来做，从 npm 源装并核对 sha512）。

第四轮（2026-10-17，Ethan：「这个新图做得非常好……未来和古地图可以再做类似的优化吗」，他三项都选了）：

- 古地图：每个地方是一座**真实的岛**（Natural Earth 1:50m 海岸线，下载前他同意了；取 18 座岛、简化后写进 `src/islands.js`，
  注明出处）。都城 = 大不列颠，任务 = 西西里，收件箱 = 冰岛，工作流 = 克里特，智能体 = 台湾，应用 = 斯里兰卡，连接器 = 塞浦路斯，
  box = 科西嘉，记录 = 爱尔兰，回普通桌面 = 塔斯马尼亚；别的页面依次是海南、北海道、撒丁……浏览器里把每座岛画成一张
  「离海岸多远」的小图，拼成一张纹理，着色器每个像素查一次。鼠标按岛的真实形状判断指着哪座（相邻的圆会互相盖住）。
  海更真实：远海一层水彩灰绿、沿岸两道点线等深线、三朵罗盘玫瑰的方位线；纸：帘纹、两块水渍。不放图标，名字在指着时
  用手写体出现。
- 未来：**太空看到的城市夜景**加上**更精细的光之城**：每个地方周围是一片城区（钠灯橙、中心偏白），每个街区的街道有自己的
  朝向、每段街道自己亮或暗，街区之间是主干道，一条暗河穿过，郊外零星的灯；核到各处是高速公路，车头灯出、尾灯进；地方仍是
  立起来的六边形平台，西面亮东面暗、侧面一排排窗灯、玻璃顶面。不放图标，名字指着时出现。
- 交互式桌面也要有**全屏和语音**（顶栏在这里没有）：右下角那排按钮前面加「说话」「全屏」，三张图都有，样子跟着图走
  （壳经 `api.listen()`、`api.fullscreen` 交给地图）。
- **窗口透明度**（系统设置，desktop.json `transparency: off | light | strong`，设置 → 外观，顶栏的外观菜单里也有）：所有桌面上
  打开的窗口和对话栏透出后面的桌面或地图——窗口底色按比例透明、后面柔化，卡片留得实一些，对话框、菜单、下拉列表保持实心
  （按 role 认）；「半透明」总开关关掉时窗口也是实的。
