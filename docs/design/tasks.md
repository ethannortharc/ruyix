## 已做

### 正在做的事：跑道（`core/workbench/src/work.jsx`）

顶栏的「正在做的事」菜单和桌面 widget `workbench:work` 里，每个在跑的运行是一条跑道：

- 每一步是一段：做完的绿色；正在做的有一道光流过；等你的琥珀色；失败的红色；还没到的灰色。并行的一块是一段，里面几路
  上下排着。
- 一个小圆在跑道上走，上面是正在干活的智能体的图标。这一步在做，它就慢慢往前走（越往后越慢，不会走到头——它不假装这一步
  做完了）；智能体每做一件事（调工具、跑命令、调模型），它闪一下；轮到你时它停下来，变成琥珀色的手。
- 刚做完的运行冲线：整条变绿，终点打勾，一道白光扫过，几秒后移到「刚做完的」里。
- 点一下打开这个运行：在等你就打开它的卡片，不然打开「过程」。

### 桌面上的光点（`core/shell/src/desktop/agents.jsx`）

- 每个在干活的智能体是壁纸上的一个光点：Claude 暖橙色，Codex 蓝色，DeepSeek 和其他智能体紫色，脚本灰色；等你的是琥珀色，
  外面有一圈在呼吸。
- 同一个运行的智能体挨在一起，用一条慢慢流动的虚线连着；运行走到下一步时，一个光点沿弧线从上一步的智能体飞到下一步的；
  智能体之间发消息时，小光珠沿着点线从一个跑到另一个；做一件事时光点放出一圈光环（失败是红色的）。
- 光点上有个小圆片（图标，或者简单的表情），鼠标放上去说它是谁、在做哪一步、哪个运行；点一下打开那个运行。
- 设置 → 通用 → 桌面上的智能体：光点和图标（默认）/ 只有光点 / 光点和表情 / 不显示。存在 `desktop.json` 的 `agents`
  （`icon | light | face | off`）。
- 有智能体在干活时，「智能」那几张动态壁纸也会活跃一点。
- 浅色壁纸上光点是盖上去的，不是叠加亮度，不然会看不见。

### 谁在干活（`core/workbench/src/activity.js`）

桌面的光点和跑道的闪光都读同一份小快照：`window.__ruyixActivity` `{ agents, links, runs }` 和事件 `ruyix:activity`。它来自
工作台本来就在轮询的数据，加上在跑的运行的最新账本条目（每条就是那一步的智能体「闪一下」）。智能体之间的消息由插件放进
`window.__ruyixActivityLinks`（`[{ from, to, at }]`，`from`/`to` 是 `<运行>:<步骤>`）并发出 `ruyix:activity-links`。
检查：`activity-check.mjs`。

### 定时规则（`core/workbench/lib/schedule.js`）

- 一次；每天几点（或者选的星期几）；每 N 分钟（至少 15 分钟）；或者一行 cron（`m h 日 月 星期`）。
- 按人的时区算，夏令时也对：每天 08:00 在切换前后都是 08:00；时钟跳过的那个时间，算跳过之后的第一分钟。
- 盒子关着、错过了几次：`dueSince` 给出最后一次该跑的时间——补跑一次，不是错过几次补几次。
- `describe` 把规则说成话：每天 08:00 · 工作日 09:30 · 每周一、三 10:00 · 每 6 小时。
- 检查：`schedule-check.mjs`。

### 性能

- 一个 canvas；光晕是事先画好的小图，每帧只是复制。有东西在干活时最多每秒约 30 帧；没有时不画；页面在后台时停下。
- 要求减少动画时（系统的设置，或者关掉动态壁纸），画一张不动的图，有变化时重画。
- 快照很小（几十个智能体以内）；账本只在有运行在跑时每几秒取一次新条目，页面在后台时不取。

## 任务的数据、定时和页面（原来的「接着做」）

### 数据

- 任务：`{ id, title, workflow, text, fields, schedule, tz, enabled, carry, catchUp, nextAt, lastAt, createdAt }`。
  运行多一个 `taskId`。
- 现有的运行：每个算一个一次性任务（迁移时生成），什么都不丢。

### 定时

- 引擎里一个计时器，到下一个 `nextAt` 时醒来：到时间的任务开始一次运行，记下 `lastAt`，算出下一个 `nextAt`。
- 上一次还没跑完：这次跳过，记一句「上一次还没完，跳过 08:00 这次」，不叠着跑。
- 盒子关着时错过了：`catchUp` 开着就补跑一次，关着就等下一次。
- 每天跑的任务：把上一次运行的结果（报告、写过的条目）交给这一次，让它只写新的内容（`carry: 'last'`）。

### 页面

- 「运行」页（2026-10-19 前叫「任务」页）：任务列表（一次性 / 定时、下次什么时候、最近一次的结果）→ 点进去是它的运行 → 再点是现在的运行页面。
- 新建：现在的表单加「什么时候跑」：现在一次 / 每天 / 工作日 / 每 N 小时 / cron。
- 跑道：定时任务没在跑的时候显示下次时间和倒计时。
- 助手：能建任务、改时间、暂停和恢复。

## 做的时候改了的

- 现有的运行不用一次性迁移成任务：每个运行开始时（`startRun`）没有任务就给它建一个一次性任务；以前的运行在工作台启动时
  补上各自的一次性任务（只做一次）。任务 id 从运行 id 来，重复做也是同一个。
- 定时任务建的时候就检查请求（工作流、表单、文件夹），不等到 08:00 才发现填错了；定时任务不带附件。
- Agent Hub 还没起来（盒子刚开机）：半小时内每次都再试；之后在任务上写明没能开始，等下一次。
- `carry` 交给下一次的只是上一次文件夹里自己的文件（不含附件、隐藏文件、链接，单个 2 MB，一共 20 MB、300 个以内）；
  在人指定的文件夹里跑的任务不用复制，下一次看到的就是上一次留下的样子。
- 时区用浏览器的（建任务时一起发过来）；助手建的任务用这个人最近建的任务的时区，盒子的 UTC 不会把 08:00 弄错。
- 「正在做的事」里，没在跑的定时任务显示「接下来」：下次时间和一条随时间填满的细线。
- 左边的列表从运行改成任务，筛选多了「定时」；一个任务的页面就是它最新的运行（或者在任务条上选的那一次），任务条在上面。
