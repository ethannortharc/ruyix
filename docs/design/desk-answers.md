# 桌面上的回答：并行地问，答案长在桌面上（设计）

2026-10-18 · Ethan：

- 桌面版和交互版都要能看到系统的版本号。
- 设置里选「桌面」才显示桌面的设置；选「交互」就列出现在支持的几种交互版（地图），选一个进去。交互版上也要有右键菜单和快捷操作。
- 现在智能体的工作和聊天不够顺手：
  - 跟它聊的时候要能**并行**——它在做一个问题时，可以接着问另一个。
  - 问题有了答案，要在**桌面上**像**抽屉**一样把这个问题和答案显示出来；可以有好几个，擦掉就是看过了。
  - 也可以用语音让它直接**放到前台**：打开一个页面显示内容；甚至问的时候就能选默认直接在前台打开，不用再点到聊天窗口去看。
  - 主聊天和整套工作的那个东西，可以在左下角或者主智能体那条附近，在工作时**长出**一个比较高的东西，里面轮换着消息，能看到过去五条左右。
  - 再从上面**长出**一些东西，像一棵树：一个问题长出一个答案；答案可以关掉，关掉就放进它的抽屉。
  - 总之要用起来更直接；随时问之前聊过的、或者系统里的信息，马上就能显示出来。

他定的（2026-10-18）：

- 答案出来时默认**在桌面上展开**（从主智能体那里长出一张卡：问题和答案）；关掉收进抽屉；擦掉算看过。语音说「打开给我看」随时放到
  前台的窗口里。设置里可以改成「先收进抽屉」或「直接开窗口」。
- 它在忙时接着问，**同时最多 3 个**在做，再问的排队。

## 样子

- **主智能体那条**（底栏上方，已有）是树根。有事在做时，它的左端向上**长出一根茎**：一列轮换的消息（最近五条左右：你问了什么、
  它在做什么、它说了什么），新的在下面、旧的往上淡出，和歌词条一个感觉。
- **一个问题是茎上的一个节**：问出去时长出一个小节点（带着问题的一句话、在做的光）；答案来了，从这个节点**长出一片叶子**——一张
  卡：上面是你的问题，下面是它的回答（文字和卡片：天气、链接、确认……），能直接点、直接答。
- **几个问题同时在做**：茎上几个节，各自亮着；先答完的先长叶子。
- **关掉叶子**：它缩回去、收进**抽屉**（茎旁边的一叠，显示几条没看的）；点开抽屉就是一列问答，每条可以再展开、放到前台、擦掉。
- **擦掉**：从抽屉里拿走，算看过（任务中心和对话记录里都还在）。
- **放到前台**：一张叶子（或语音「打开给我看」）在一个窗口里打开完整的内容。
- 没事在做、抽屉里也没有没看的：茎收回去，只剩那条。

### 叶子放在哪、一张卡只出现一次（2026-10-20）

Ethan 在盒子里问了一件事，桌面上弹出两块，还叠在一起：「我只问了他一个处理，然后他最后返回的信息给我的是两个弹窗……两个弹窗是不是要更
平铺一些，或者是找一些空的地方来放？另外，为什么两个弹窗内容还是有一些重叠？……ask on this 的时候……是不是也可以加一个语音输入啊？」

原因：回答里有一个还等他选的选择题，叶子里画了一次，主智能体那条上方的「等你回答」又画了一次；两块都固定在那条的左上方，不看桌面上
有什么，压在小组件上、也互相压。

- **一张卡只在一处**：等你回答的卡，长在哪片叶子里就只在叶子里答；那条只在卡不在任何叶子里时（叶子收进了抽屉、放到了前台）才把它
  托在上方。有窗口在前、树折成一行时，这一行变成琥珀色的「等你回答 · 问题」，不再另起一个小条。
- **叶子找空处放**：每片叶子在主智能体那条上方、桌面空着的地方——避开时钟、左边打开的东西、小组件（右边一列和拖出来的）、等你回答的卡、
  茎，彼此也不叠；最新的放在原来的位置（茎的右边），其余的就近找；地方不够整片放时变矮（文字可以滚），连矮的也放不下就进抽屉。
  一处也没有时最新的那片照样放在原位（总得看得见回答）。算法在 `core/shell/src/desktop/place.js`。
- **还在等你回答的选择固定在叶子底部**：文字在上面滚，选择题、确认一直露在输入框上方，不用往下翻。
- **叶子里只放最后那段话**，按 Markdown 显示（粗体、编号、列表）：做的过程中说的话（「我在看两件事……」）茎上已经轮换着显示过，叶子里只留最后一步之后说的；放到前台的窗口
  和对话里还是全部。
- **只在对话里画的东西点名**：它这一轮存的工作流草稿、跑的草稿（带「启用」等按钮）叶子画不了，就在叶子里写一行「工作流草稿：名字 ·
  到对话里看」，点了打开对话——回答里说「上面的卡片」时，那张卡就在这一行指向的地方。
- **「接着问这个…」能说话**：输入框右边一个麦克风。框是空的：说完先出「听到"……" 取消 / 发送」，两秒后作为接着问这个问题发出，和主智能体
  那条的麦克风一样；框里已经打了字：说的话接在打的字后面，自己按回车发。

## 并行

- 每个问题是一个**任务**（agent-tasks.md）：问出去就是在做；答案就是它的结果；看过（擦掉）的一问一答就完成了。
- 主智能体同时最多 3 个问题在做，各自有自己的会话（不互相等）；第 4 个排队，茎上显示「排着」。
- 接着问同一件事（「再详细点」「换成小红书的口吻」）：落在同一个任务、同一片叶子上，不新开。
- 随时问之前聊过的、系统里的信息：这类问题快，不用排队等正在做的大事。

## 版本号

- 桌面版：顶栏左边 Ruyix 标志的菜单里「关于 Ruyix」：Ruyix 的版本、这份程序的提交号和时间、dsh 的版本、盒子的名字；设置 → 通用最下面
  也有一行。
- 交互版：右键菜单里「关于 Ruyix」，和地图角上一行小字。

## 设置里的模式

设置 → 外观（或通用）：「桌面 / 经典 / 交互」三选一。选桌面，只显示桌面的设置（壁纸、组件……）；选交互，列出现有的几种交互版
（古地图、星图、未来……，各带一张小图和一句话），点一个就进去；它们各自的设置也在这里。

## 分工

- **workspace-ce**：并行——主智能体同时最多 3 个问题、每个自己的会话、第 4 个排队、同一件事落回同一个任务；每个问题的进度和答案作为
  事件给桌面（问题、在做的一句、答案的文字和卡片、它的任务）；「放到前台」和默认怎么出现的设置；语音「打开给我看」。
- **workspace-15**：桌面上的样子——茎、节、叶子、抽屉、收回去；交互版的右键菜单；交互版上的版本号。
- **workspace-d0**：这份设计；版本号（从哪来、怎么显示、桌面版的「关于 Ruyix」）；设置里的模式和交互版列表；答案在桌面上的数据
  （`@ruyix/shell` 里一份共用的问答单子，和「正在做」的单子一样：谁都能放、桌面读一份）；在盒子里用真模型走一遍。

## 先后

1. 同时开始：并行（ce）、问答单子和版本号（d0）——先把接口发出来。
2. 茎、节、叶子、抽屉（15），接上问答单子。
3. 设置里的模式、交互版右键菜单。
4. 盒子里走一遍：问一个要做一会儿的，接着问一个快的，快的先长叶子；关掉、擦掉、语音「打开给我看」。
